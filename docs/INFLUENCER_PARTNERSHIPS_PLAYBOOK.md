# Influencer Partnerships Playbook

Source: `Documents/Spiritual_AI_Influencer_Guide.docx` (2026-07-18).

The Influencer Partnerships department represents `https://www.spiritualai.store`. It should introduce creators to the free Consciousness Blueprint first, then propose the approved referral program only when the experience is a genuine fit.

## Approved referral terms

- Audience discount: 10%.
- Creator commission: 50% of the amount actually paid after discount.
- Attribution: 30 days after link click; code can also be entered at checkout.
- Setup: SpiritualAI.store → complete free chat → create account → Profile → Referral tab → choose/create code → copy link.
- Payout status: visible in the creator referral dashboard. Payout details: `admin@spiritualai.store`.

The agent must verify commercial terms against the live program before any creator-facing approval.

## Safety and outreach

First contact, changed messages, referrals terms, payout actions, private data access, and public posts remain approval-gated. The department may research public creator fit and draft professional, value-led outreach. It must not guarantee income, present the product as medical/clinical advice, spam, scrape private data, or claim an action has occurred when it has only drafted it.
